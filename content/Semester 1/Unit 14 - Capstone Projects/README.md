## How this chapter works

Unlike earlier units, this chapter is not a sequence of taught topics — each entry is a single extended project brief, worked through in six stages that mirror the semester's own progression: input and validation, a menu-driven loop, functions, file persistence, a redesign using classes, and finally exception handling with planted bugs to find and fix. Each stage ends with reflection questions rather than answers, meant to be worked through and discussed, not just read.

An instructor or self-learner picks one project to build end to end; all ten cover the same six-stage arc so any one of them exercises the full semester.
