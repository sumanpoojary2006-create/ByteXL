## How this chapter works

Unlike earlier units, this chapter is not a sequence of taught topics. Each entry is a single extended project brief, worked through in stages that mirror the course's own progression: schema design and normalization, core SQL, retrieval and analytics, advanced querying, transactions, performance tuning, and finally a production-ready security and automation layer. Each stage ends with reflection questions rather than answers, meant to be worked through and discussed, not just read. Unit 1 (Database Foundations) is intentionally not part of this progression, since it precedes any hands-on schema work.
