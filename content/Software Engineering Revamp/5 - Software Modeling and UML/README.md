# Unit 5 - Software Modeling and UML

Learning outcome: model system structure and behaviour using common UML diagrams. Source: `Course Blueprint for Software Engineering.xlsx`, sheet `Syllabus`.

| # | Topic | Concepts |
| --- | --- | --- |
| 43 | Principles of Modelling | Abstraction, views, models as communication, when a model is not worth drawing |
| 44 | Unified Modeling Language | Structural vs behavioural diagrams, notation basics |
| 45 | Use Case Diagrams | Actors, include and extend, system boundary |
| 46 | Class Diagrams | Attributes, operations, associations, multiplicity, generalisation, object diagrams |
| 47 | Sequence Diagrams | Lifelines, messages, alternatives and loops |
| 48 | Activity Diagrams | Flows, forks and joins, swimlanes |
| 49 | State Machine Diagrams | States, transitions, guards, events |
| 50 | Component and Deployment Diagrams | Interfaces, dependencies, packages, runtime nodes |
| 51 | Data Modelling | ER diagrams, mapping entities to classes and tables |
| 52 | Agile and Lightweight Modelling | C4 model, whiteboard sketching, diagrams-as-code with Mermaid or PlantUML |

This unit is conceptual: it has no code snippets. Worked examples are given as tables and prose. Each image is introduced by a `Visual:` comment that records its brief.
