# Unit 6 - Design Principles and Software Architecture

Learning outcome: apply design principles to modularise a system and justify an architectural style. Source: `Course Blueprint for Software Engineering.xlsx`, sheet `Syllabus`.

| # | Topic | Concepts |
| --- | --- | --- |
| 53 | Software Design Process | Design levels, design as decision-making, design documents |
| 54 | Modularity, Abstraction and Information Hiding | Parnas's criteria, interfaces vs implementations |
| 55 | Coupling and Cohesion | Types and levels, measuring and reducing coupling |
| 56 | SOLID Principles | Single responsibility, open-closed, Liskov, interface segregation, dependency inversion |
| 57 | Additional Design Principles | DRY, KISS, YAGNI, composition over inheritance, Law of Demeter, separation of concerns |
| 58 | Abstract Data Types and Invariants | Representation invariants, abstraction functions, immutability |
| 59 | API Design | Contracts, naming, error contracts, versioning, backward compatibility |
| 60 | Object-Oriented Design | GRASP, CRC cards, domain modelling, domain-driven design basics |
| 61 | Software Architecture Fundamentals | Significant decisions, quality attributes and trade-offs |
| 62 | Architectural Styles | Layered, client-server, pipe-and-filter, MVC and MVVM, event-driven, plugin |
| 63 | Hexagonal and Clean Architecture | Ports and adapters, dependency rule, testability benefits |
| 64 | Monolithic and Microservice Architectures | Boundaries, team alignment, trade-offs at a conceptual level |
| 65 | Architecture Documentation and Evaluation | Views, architecture decision records, fitness functions, design reviews |
| 66 | Fault Tolerance and Concurrency in Design | Error handling strategies, race conditions, thread safety basics, immutability |
| 67 | Human-Centred Design | Usability heuristics, wireframes, prototyping, design-developer hand-off |

This unit is conceptual: it has no code snippets. Worked examples are given as tables and prose. Each image is introduced by a `Visual:` comment that records its brief.
