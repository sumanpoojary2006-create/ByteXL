## How this chapter works

Each entry is a complete mini-project brief rather than a taught topic. Instructors can assign projects at the recommended checkpoints while all project material remains in one course-level chapter.

The Software Engineering course is conceptual and contains no code, so these projects produce engineering artefacts rather than programs: memos, requirement packs, plans, models, registers and reports. No project needs an internet connection, special software or a downloaded dataset. All starting material is written into the brief, so every student works from the same facts and answers can be compared and discussed.
