# Unit 4 - Software Project Management

Learning outcome: estimate effort and schedule, plan a project and manage its risks. Source: `Course Blueprint for Software Engineering.xlsx`, sheet `Syllabus`.

| # | Topic | Concepts |
| --- | --- | --- |
| 32 | Project Management Fundamentals | Scope, time, cost, quality, work breakdown structure |
| 33 | Software Estimation Techniques | Cone of uncertainty, expert judgement, Delphi, planning poker, story points, velocity |
| 34 | Size Estimation | Lines of code, function point analysis, worked numericals |
| 35 | COCOMO Models | Basic, intermediate and COCOMO II overview, effort and schedule calculations |
| 36 | Project Scheduling - PERT and CPM | Gantt charts, PERT, CPM, slack, crashing a schedule |
| 37 | Risk Management | Identification, probability and impact, mitigation, risk register |
| 38 | Team Organisation | Brooks's Law, Conway's Law, team size limits, onboarding |
| 39 | Software Configuration Management | Baselines, change requests, change control board, branches and release lines in Git |
| 40 | Project Monitoring and Metrics | Burn-down charts, cycle time, earned value, DORA metrics as a concept |
| 41 | Outsourcing and Engagement Models | Fixed-price vs time-and-materials, outsourcing, services vs product companies |
| 42 | Technical Debt Management | Visibility, prioritisation, negotiating time for repayment |

This unit is conceptual: it has no code snippets. Worked examples are given as tables and prose. Each image is introduced by a `Visual:` comment that records its brief.
