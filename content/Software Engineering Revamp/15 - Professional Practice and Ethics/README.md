# Unit 15 - Professional Practice and Ethics

Learning outcome: apply professional and ethical standards and communicate clearly with technical and non-technical people. Source: `Course Blueprint for Software Engineering.xlsx`, sheet `Syllabus`.

| # | Topic | Concepts |
| --- | --- | --- |
| 156 | Professional Ethics | ACM and IEEE code of ethics, whistleblowing, duty to users |
| 157 | Case Studies in Software Failure | Therac-25, Ariane 5, Knight Capital, Boeing 737 MAX software, the 2024 CrowdStrike outage |
| 158 | Intellectual Property | Copyright, patents, trade secrets, employee IP and moonlighting rules |
| 159 | Open-Source Licences | MIT, Apache, GPL, AGPL, compliance in products, contributor agreements |
| 160 | Software Law and Regulation | IT Act, DPDP Act, contracts and liability, overview of AI regulation such as the EU AI Act |
| 161 | Fairness and Societal Impact | Sources of bias in data and design, impact assessment, inclusive design |
| 162 | Sustainable Software Engineering | Energy use of software, efficient design choices, carbon-aware thinking |
| 163 | Technical Communication | Design docs, RFCs, status updates, clear bug and incident write-ups |
| 164 | Teamwork and Collaboration | Giving and receiving feedback, conflict, psychological safety, disagree-and-commit |
| 165 | Stakeholder Communication | Explaining trade-offs, managing expectations, saying no with options |

This unit is conceptual: it has no code snippets. Worked examples are given as tables and prose. Topics 158 and 160 are engineer's overviews and not legal advice. Each image is introduced by a `Visual:` comment that records its brief.
