# Unit 1 - Foundations of Software Engineering

Learning outcome: explain why software engineering exists and weigh cost, speed and quality trade-offs. Source: `Course Blueprint for Software Engineering.xlsx`, sheet `Syllabus`.

| # | Topic | Concepts |
| --- | --- | --- |
| 01 | Introduction to Software Engineering | Software crisis, programming vs engineering, essential vs accidental complexity |
| 02 | Software Types and Application Domains | System, application, embedded, web, mobile, AI-enabled; product vs project vs service |
| 03 | Software Quality Attributes | Maintainability, dependability, security, efficiency, usability; ISO 25010 overview |
| 04 | Software Development Life Cycle | Phases, artefacts, hand-offs, where defects are born and caught |
| 05 | Software Complexity and Scale | Codebase growth, Hyrum's law, why small habits compound |
| 06 | Roles in Software Teams | SDE, QA/SDET, PM, designer, tech lead, SRE, data/ML engineer |
| 07 | Software Economics and Trade-offs | Cost of change, build vs buy, time-to-market, quality vs speed |

This unit is conceptual: it has no code snippets, and each lesson opens by explaining the idea itself. Worked examples are given as tables and prose. Each image is introduced by a `Visual:` comment that records its brief.
