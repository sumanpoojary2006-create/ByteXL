# Unit 7: Object-Oriented Design & Design Patterns

Learn the object-oriented ideas behind good design and the classic patterns that capture reusable solutions: objects, polymorphism, and responsibilities; composition over inheritance; why design patterns exist; the Singleton, Factory, Builder, Prototype, Adapter, Facade, Decorator, Composite, Strategy, State, Observer, Command, Template Method, and Iterator patterns; dependency injection and inversion of control; and the anti-patterns and code smells that signal a design in trouble. Conceptual and theory-focused: no code examples. Source of truth: `Course_Blueprint_for_Software_Engineering.xlsx`, sheet `Syllabus`, Unit 7.

3 chapters, 12 topics.
