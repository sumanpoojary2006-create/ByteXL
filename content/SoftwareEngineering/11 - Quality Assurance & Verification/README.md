# Unit 11: Quality Assurance & Verification

Learn how quality is defined, built in, and assured: software quality definitions and models, quality assurance versus quality control, code reviews and inspections, static analysis and linting, software metrics, defect management and root-cause analysis, reliability and availability, formal specification and verification, safety-critical software, and the lessons of real failures. Conceptual and theory-focused: no code examples. Source of truth: `Course_Blueprint_for_Software_Engineering.xlsx`, sheet `Syllabus`, Unit 11.

4 chapters, 10 topics.
