# Unit 2: Software Process Models & Agile Methods

Understand how software work is organised over time: why teams use a process, the main sequential, iterative, and risk-driven models, the values and frameworks of agile development, and the everyday practices that make agile work. Conceptual and theory-focused: no code examples. Source of truth: `Course_Blueprint_for_Software_Engineering.xlsx`, sheet `Syllabus`, Unit 2.

4 chapters, 21 topics.
