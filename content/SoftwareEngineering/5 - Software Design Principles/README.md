# Unit 5: Software Design Principles

Learn what makes a software design good: what design is, abstraction and information hiding, modularity and decomposition, cohesion and coupling, encapsulation and interface design, the SOLID principles and other heuristics, design by contract, designing for change, evaluating design quality, and the basics of user interface and user experience design. Conceptual and theory-focused: no code examples. Source of truth: `Course_Blueprint_for_Software_Engineering.xlsx`, sheet `Syllabus`, Unit 5.

4 chapters, 12 topics.
