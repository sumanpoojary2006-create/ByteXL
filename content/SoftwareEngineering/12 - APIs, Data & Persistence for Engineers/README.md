# Unit 12: APIs, Data & Persistence for Engineers

Learn how software components expose and consume interfaces and how application data is represented, stored, protected, accessed, cached, and shared safely: API styles and REST design, versioning and documentation, data formats and serialisation, relational databases and SQL, transactions and integrity, NoSQL and choosing a data store, object-relational mapping, caching, and concurrency. Conceptual and theory-focused: no code examples. Source of truth: `Course_Blueprint_for_Software_Engineering.xlsx`, sheet `Syllabus`, Unit 12.

3 chapters, 10 topics.
