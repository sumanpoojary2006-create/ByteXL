# Unit 3: Requirements Engineering

Learn how to discover what a system must do and record it so that everyone understands the same thing: identifying stakeholders, eliciting needs, writing use cases, stories, and requirement statements, analysing and negotiating conflicts, prioritising, specifying, validating, tracing, and managing change. Conceptual and theory-focused: no code examples. Source of truth: `Course_Blueprint_for_Software_Engineering.xlsx`, sheet `Syllabus`, Unit 3.

3 chapters, 12 topics.
