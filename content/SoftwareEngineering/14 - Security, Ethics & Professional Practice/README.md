# Unit 14: Security, Ethics & Professional Practice

Learn the responsibilities that surround all software work: security as an engineering concern, the secure development life cycle, threat modelling, common vulnerabilities, safe handling of data, authentication and authorisation, secrets, cryptography and dependencies, security testing, privacy by design, professional ethics and case studies of harm, intellectual property and licensing, accessibility, sustainable software, cloud-native development, engineering for machine learning, AI-assisted development, technical writing, careers and continuous learning, and a capstone that brings the course together. Conceptual and theory-focused: no code examples. Source of truth: `Course_Blueprint_for_Software_Engineering.xlsx`, sheet `Syllabus`, Unit 14.

6 chapters, 20 topics.
