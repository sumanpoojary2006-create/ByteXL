# Unit 4: Modeling Software with UML

Learn why and how software is modeled: the purpose of modeling, the main UML diagrams for structure (use case, class, component, deployment) and behaviour (sequence, activity, state machine), data and domain modeling, and lightweight approaches such as sketching and the C4 model. Conceptual and theory-focused: no code examples. Source of truth: `Course_Blueprint_for_Software_Engineering.xlsx`, sheet `Syllabus`, Unit 4.

3 chapters, 11 topics.
