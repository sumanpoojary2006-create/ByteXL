# Introduction to Artificial Intelligence

6 teaching units, each covering the topics listed in the course blueprint. Source of truth: `Course Blueprint for Introduction to Artificial Intelligence.xlsx`, sheet `Syllabus`.

Artificial Intelligence is the science of building systems that can perceive their environment, reason about problems, learn from experience, and make intelligent decisions. This course introduces the fundamental principles of AI, progressing from classical approaches such as search, knowledge representation, and reasoning to machine learning, deep learning, and modern foundation models. Rather than viewing AI as a collection of algorithms, students develop a unified understanding of how intelligent systems perceive, reason, learn, and act, while exploring their applications across real-world domains.

## Prerequisites

No prior artificial intelligence knowledge is assumed. The reading material can be followed without writing any code.

Working Python is assumed from Unit 2 onward, where the lessons carry runnable examples, and for the mini projects in chapter 7. A student who has completed a first Python course has enough. The first mini project supplies its scaffolding, because Unit 1 teaches no code.

Every code example and every project runs on the Python standard library alone, with one exception: the machine learning project uses scikit-learn, matching Unit 4. Nothing needs a GPU, an API key, a downloaded dataset, or an internet connection.

Chapter 7 is not a teaching unit. It holds one project brief per unit, each assignable at the checkpoint named in its entry, with all project material kept together rather than scattered through the units.

## The Mental Model Running Through the Course

Think of an intelligent system as a decision-making engine that continuously perceives, reasons, learns, and acts to achieve a goal. Like humans, intelligent systems solve problems through four fundamental capabilities: they perceive information from the environment, represent knowledge about the world, reason using logic or learn from experience, and act by selecting the most appropriate action to achieve an objective.

Classical AI focuses on representing knowledge and reasoning about problems. Machine Learning enables systems to improve by learning from data. Deep Learning automatically discovers complex representations from large datasets. Modern Foundation Models integrate perception, reasoning, language understanding, and generation into increasingly capable intelligent systems. Across the six units, students progressively build this mental model, understanding not only individual AI techniques but also how these techniques work together to create intelligent behaviour.
