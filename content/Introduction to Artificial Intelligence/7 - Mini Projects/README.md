## How this chapter works

Each entry is a complete mini-project brief rather than a taught topic. Instructors can assign projects at the recommended checkpoints while all project material remains in one course-level chapter.

Every project runs on the Python standard library alone, with one exception: the machine learning project uses scikit-learn, matching the library introduced in Unit 4. No project needs an internet connection, an API key, a downloaded dataset, or a GPU. Any data a project needs is either written into the brief or generated by the student's own code with a fixed seed, so results are reproducible and every student's output can be compared against everyone else's.
