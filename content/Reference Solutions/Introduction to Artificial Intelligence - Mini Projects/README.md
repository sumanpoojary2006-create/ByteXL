# Reference Solutions: AI Mini Projects

Instructor copies of the six mini projects in `content/Introduction to Artificial Intelligence/7 - Mini Projects/`. One file per brief, named to match. These are kept outside the course folder so they are never uploaded alongside the student material.

Each script is self-contained and prints the output shown in its brief's Sample Run. Everything runs on the standard library except `loan_screening_end_to_end.py`, which uses scikit-learn as Unit 4 does.

Run one with:

```
python3 "rule_based_helpdesk.py"
```

The numbers a student produces will differ where a brief asks them to invent their own data (test messages, review sets, extra rules). The shape of the result should not: the misfiring rule, the greedy detour, the crossover point, the two-sided learning rate failure.
