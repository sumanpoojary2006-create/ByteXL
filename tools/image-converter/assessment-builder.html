Custom topic blueprint
For courses where assessment topics don’t map 1:1 to curriculum units — set exact MCQ / coding counts per topic instead of auto-discovering by unit.
Each row is {"title","topics","mcqCount","codingCount","duration","difficulty"}. topics must match the topics tag on Set 2 questions in ByteXL (e.g. strings, lists-and-tuples) — list several to merge them into one test. difficulty is optional ("easy", "medium", "hard", or an array to allow several) and filters both MCQ and coding pools; omit it to draw from any difficulty. Questions are spread evenly across merged topics and picked in a fixed order, so re-running with the same inputs is deterministic.
